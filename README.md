# موقع Team Salon – فرع النخيل

موقع ثابت (HTML/CSS/JS بدون أي إطار عمل معقّد) مبني عشان يكون سهل الاستضافة في أي مكان، وسريع، وصديق لمحركات البحث (SEO) من الأول.

## ليه HTML/CSS عادي؟
- محركات البحث بتقرأ صفحات HTML الثابتة مباشرة، من غير ما تستنى تحميل JavaScript — ده أفضل حاجة لـ SEO.
- تقدر تستضيفه في أي استضافة عادية (cPanel)، أو مجانًا على Netlify / Vercel / GitHub Pages.
- كل صفحة فيها Title، Meta Description، Canonical، وبيانات Schema.org (LocalBusiness / Article) جاهزة.

## هيكل الملفات
```
index.html          الصفحة الرئيسية
services.html        صفحة الخدمات
offers.html          صفحة العروض والأسعار
contact.html         صفحة التواصل والموقع
articles/index.html  قائمة المقالات
articles/*.html      كل مقالة في ملف مستقل
assets/css/style.css التصميم والألوان
assets/js/main.js    قائمة الموبايل (menu toggle)
assets/images/       الشعار وصورة العروض
robots.txt           تعليمات لمحركات البحث
sitemap.xml          خريطة الموقع
```

## قبل الرفع (لازم تعدّل)
1. **الدومين**: كل الروابط `https://teamsalon-alnakheel.sa/` في الملفات (canonical, sitemap, og:image) لازم تتغيّر للدومين الحقيقي بتاعك.
2. **مواعيد العمل**: مش متذكورة، فحطينا بدالها "تواصل معنا لمعرفة المواعيد" — لو عندك مواعيد ثابتة ضيفها في `contact.html` وفي الـ Schema بـ `openingHoursSpecification`.
3. راجع الأسعار في `offers.html` من وقت لآخر لو اتغيّرت.

## إزاي تضيف مقالة جديدة (SEO)
1. اعمل نسخة من أي ملف موجود في `articles/` وسمّيه بعنوان الرابط (مثلاً `articles/skin-care-tips.html`).
2. غيّر: `<title>`, `meta description`, `canonical`, `h1`, ومحتوى المقال.
3. حدّث بيانات `Article` schema (headline, datePublished).
4. ضيف كارت المقالة الجديدة في `articles/index.html` وفي قسم "المقالات" بالصفحة الرئيسية `index.html`.
5. ضيف رابط المقالة في `sitemap.xml`.

نصيحة SEO: كل مقالة لازم تجاوب على سؤال حقيقي بيدور عليه الناس في جوجل (مثلاً "أفضل صالون حلاقة في النخيل" أو "كام سعر المساج في الرياض")، وتربط في نهايتها بصفحة الخدمة أو العروض عشان تحول القارئ لعميل.

## الخطوة الجاية (اختياري)
لو حبيت مستقبلًا تدير مقالات كتير أو محتوى متغيّر بشكل متكرر، تقدر تنقل نفس التصميم على مولّد مواقع ثابتة زي Astro أو Eleventy — هيدّيك نفس سرعة الـ SEO لكن مع Templates بدل تكرار الهيدر والفوتر يدويًا في كل صفحة.
